# Configurando uma Instância de Banco de Dados na Azure

## Descrição do Projeto

Este repositório foi desenvolvido como parte do desafio da DIO com o objetivo de documentar os conhecimentos adquiridos sobre configuração de uma instância de Banco de Dados na Microsoft Azure.

## Objetivos do Laboratório

Durante este laboratório, foram abordados conceitos importantes relacionados à criação e gerenciamento de bancos de dados na nuvem utilizando a plataforma Azure.

Os principais objetivos foram:

* Aprender a configurar uma instância de banco de dados na Azure;
* Entender os recursos de segurança e conectividade;
* Conhecer os serviços de banco de dados disponíveis na plataforma;
* Utilizar o portal Azure para gerenciamento de recursos;
* Documentar o processo utilizando GitHub e Markdown.

## O que aprendi

### Introdução aos Bancos de Dados na Azure

Aprendi que a Microsoft Azure oferece diversos serviços de banco de dados gerenciados, permitindo maior facilidade de administração, escalabilidade e segurança.

Entre os principais serviços disponíveis estão:

* Azure SQL Database;
* Azure Database for MySQL;
* Azure Database for PostgreSQL;
* Azure Cosmos DB.

### Processo de Configuração

Durante o laboratório, aprendi o passo a passo para criar uma instância de banco de dados:

1. Criar um grupo de recursos;
2. Escolher o tipo de banco de dados;
3. Definir nome do servidor e banco;
4. Configurar login e senha de administrador;
5. Selecionar região e desempenho;
6. Configurar regras de firewall;
7. Revisar e criar a instância.

### Configurações Importantes

Também aprendi sobre:

* Controle de acesso;
* Segurança de rede;
* Backup automático;
* Escalabilidade;
* Monitoramento de desempenho;
* Alta disponibilidade.

## Benefícios do Banco de Dados em Nuvem

O laboratório mostrou diversas vantagens da utilização de bancos de dados na nuvem:

* Maior segurança;
* Facilidade de gerenciamento;
* Redução de custos com infraestrutura;
* Escalabilidade sob demanda;
* Backup e recuperação simplificados.

## Conclusão

Este desafio foi importante para consolidar os conhecimentos sobre bancos de dados na Microsoft Azure. A prática ajudou a compreender melhor o processo de configuração, gerenciamento e segurança de serviços de banco de dados em ambiente de nuvem.
